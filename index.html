NeurIPS 2025

IRRISIGHT

Large-scale multimodal benchmark for remote-sensing classification, vision-language grounding, and model evaluation.

Paper · Code

  • 1.4M+ ML-ready patches across 20+ U.S. states; released on Hugging Face.
  • 58% improvement from multimodal fusion over single-modality baselines.
  • Best multimodal model (KIIM): 95.8 Acc · 94.6 F1.
  • Supervised and semi-supervised training pipelines with teacher-student knowledge distillation.

IJCAI 2026

AG-STELLA

Knowledge-guided spatio-temporal transformer for image classification and temporal reasoning using foundation-model embeddings and structured feature fusion.

Paper · Code

  • Evaluated across 3 U.S. states (UT, CO, WA) on 21K+ labeled samples.
  • +16% macro accuracy and +27% F1 over strong vision and foundation-model baselines.
  • Introduces Temporal Transition Latent Space (TTLSP) and Temporal Feature Fusion (TFF).
  • Stronger cross-state generalization — directly relevant to large-scale model transfer.

IJCAI 2025

KIIM — Knowledge-Informed Multimodal Classification

Knowledge-informed deep learning for multimodal scene classification and grounded reasoning — the model anchoring the IRRISIGHT benchmark.

Paper · Code

  • Fuses RGB, structured priors, and visual embeddings for robust classification.
  • Achieves 95.8 Accuracy · 94.6 F1, the top result on benchmark data.
  • Demonstrates the value of knowledge-informed multimodal fusion at production scale.

WACV 2026

PRISM-CAFO

Prior-conditioned, infrastructure-first remote-sensing pipeline for explainable CAFO detection — combining YOLO detection, SAM segmentation, and multimodal fusion.

Paper · Code

  • Pipeline: YOLO detection → SAM segmentation → descriptor extraction → multimodal classification → explainability.
  • Improves interpretability and cross-region robustness for large-scale livestock monitoring.
  • macro-F1 up to 0.841 and +15% over best baseline (Swin-B + PRISM-CAFO).
  • 38k patches across 20 US states (0.6 m NAIP), multi-species labels (poultry, swine, beef, dairy).

KDD 2025

IrrMap

National-scale benchmark and baseline suite for large-scale geospatial classification and model generalization.

Paper · Code

  • Standardized end-to-end processing from raw geospatial sources to ML-ready samples at U.S. scale.
  • Published baselines spanning CNN, transformer, and vision-language model families.
  • Cross-state generalization evaluation for real-world model transfer.

CVPR Workshop 2026

CAFOSat: A Strongly Annotated Dataset for Infrastructure-Aware CAFO Mapping Using High-Resolution Imagery

Multimodal geospatial framework for large-scale CAFO understanding using high-resolution satellite imagery, spatial context, and infrastructure-aware reasoning.

Paper · Code

  • Integrates visual, structural, and contextual information to detect and classify barns, manure lagoons, and feed storage facilities across heterogeneous landscapes.
  • Emphasizes scalable infrastructure mapping, multimodal representation learning, and interpretable scene understanding.
  • Supports environmental monitoring and precision agriculture through infrastructure-aware geospatial reasoning.
